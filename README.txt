El Pollo Loco

El Pollo Loco is a browser-based jump-and-run game built with HTML, CSS, and JavaScript. The player controls Pepe through a desert world, collects coins and salsa bottles, avoids or defeats chickens, and finally fights the end boss.

The goal of the game is to move through the level, collect useful resources, survive enemy encounters, and defeat the final boss. The game supports keyboard controls on desktop and touch controls on mobile devices, so players can run, jump, and throw bottles depending on their device.

This project is intended as a learning and practice project for object-oriented JavaScript development. It demonstrates how a 2D browser game can be structured with canvas rendering, class-based game objects, collision detection, animations, status bars, sound handling, level creation, and responsive controls.

Main parts of the project:
- index.html starts the game and includes the styles, models, level data, and game logic.
- css/ contains the layout, screens, controls, and responsive styling.
- js/ contains the main game logic, audio handling, controls, loading behavior, and screen changes.
- models/ contains the classes for the character, enemies, objects, world, collisions, rendering, and status bars.
- levels/ contains the level setup.
- img/ and audio/ contain the visual and sound assets used by the game.

The project is designed to run directly in the browser and to show the basic structure of a small object-oriented JavaScript game in a practical way.
